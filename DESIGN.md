# RM1 / visible by design

Ukrainian advertising production company in Myrhorod, serving Poltava region. A catalogue and portfolio, with a quote request assembled for email. No checkout or invented prices.

Visual thesis: the physical weight and illumination of a fabricated sign, expressed through a black industrial canvas, oversized oblique Unbounded 700 headings and warm signal red. Onest handles all body text. Only two type families. No negative tracking on uppercase.

Hero: original generated photograph of a red acrylic dimensional R, right aligned. Left text stays outside the object. Image is labelled a visual concept. Real client photographs appear in portfolio with source provenance in ASSETS.md.

Palette: #111110 background, #1b1b19 surfaces, #f2f0e9 text, #a3a29b muted, #ff3c29 accent. Max-width 1520px. Gutters 24–60px. Section rhythm 96–144px. Grid gap 16px; upper content gap 30px. Pills for menus, filters, and actions. Glass only where a real image layer sits below it. Film grain is a static 200px tile at 5% opacity.

Sequence: full-screen hero / services preview / continuous portfolio ribbon / editorial production statement with interactive 3D sign / four practical project steps / quote invitation / footer. Catalogue, five service pages, filtered portfolio, company, and contacts are separate HTML pages.

Motion: one dominant continuous ribbon, 420×270 tiles, 12px gap, 16px radii, scroll contribution 0.3. GSAP primary; Lenis sole smooth-scroll engine. Cursor lerp 0.12. Three.js is an on-demand dimensional letter study with metal sides and red/white acrylic; pointer response is bounded, with no idle spin. No horizontal pin or blur reveals. Durations .3/.5/.6s, cubic-bezier(.215,.61,.355,1). Reduced motion keeps static final states and a photographic 3D fallback.

Reference traits only: firensmoke (type/contrast), Damn Good Brands (responsive interaction), Natura Lab (compact numerals/pills), Arteforma (ribbon pacing). No third-party reference assets or copy reused. The unnamed Email Landing Page is interpreted solely from the user's specified glass/grain material rules.
